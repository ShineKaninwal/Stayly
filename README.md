# Stayly

Stayly is a modern full-stack accommodation discovery and booking platform designed to make finding the right stay simple, fast, and convenient.

Users can explore properties, search by location and preferences, filter stays based on different criteria, view property details, and manage their bookings through a clean and responsive interface.

## Live Demo

Frontend:
https://stayly-ten.vercel.app/

Backend API:
https://stayly-backend.onrender.com

GitHub:
https://github.com/ShineKaninwal/Stayly

## Features

- Modern responsive accommodation platform
- Property discovery and search
- Location-based search
- Property categories
- Price filtering
- Guest filtering
- Rating filtering
- Property details
- User authentication
- Booking functionality
- PostgreSQL database
- REST API backend
- Responsive React interface
- Cloud deployment
- Separate frontend and backend architecture

## Property Categories

Stayly supports different types of stays and experiences, including:

- Beach
- Mountains
- Amazing Views
- Countryside
- Pools
- Luxury
- Trending
- Nature
- City
